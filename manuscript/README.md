# Manuscript sources

The text of the article and the supplementary file, and the scripts that build them
from the result files in [`../results`](../results).

## Building

```bash
cd manuscript
python assemble.py
```

`assemble.py` reads the section drafts, inserts the numbered tables from
`../results/manuscript` and the figures from `../results/figures`, resolves the
`{T_*}` and `{F_*}` cross-references, writes `manuscript.md` and
`supplementary.md`, and then calls `build_manuscript.py` to produce the `.docx`
files in the repository root.

It finds the repository automatically when run from this directory. Set `ZSH_REPO`
to override.

Two things are needed that this repository does not contain:

| | |
|---|---|
| `pandoc` | on the PATH (tested with 3.10) |
| MDPI Word template | pandoc uses it as a reference document for styling. It is MDPI's own file and is not redistributed here; set `ZSH_MDPI_TEMPLATE` to your copy |

Without the template the Markdown is still written; only the `.docx` step fails.

## Checking the numbers

```bash
python verify_numbers.py
```

Every numerical claim in `manuscript.md` and `supplementary.md` is recomputed from
the saved result files and compared with the string the text uses. It exits
non-zero if any disagrees. The same check runs as the last step of
`../RUN_ALL.py`.

## Files

| | |
|---|---|
| `draft_*.md` | the section drafts; these are the sources you edit |
| `manuscript.md`, `supplementary.md` | generated by `assemble.py`, committed so the text can be read and diffed without a build |
| `references.json` | the reference list |
| `references_verified.md` | how each reference was checked against CrossRef or the publisher |
| `crossref_v1_refs.json` | CrossRef records retrieved for that check |
| `assemble.py`, `build_manuscript.py`, `verify_numbers.py` | the build and the check |

## Not included

The correspondence with the reviewers and the editor — the point-by-point replies,
the cover letters and the editor replies — is kept out of this repository while the
article is under review.

Placeholders in `{BRACES}` that survive a build are listed by `assemble.py`. One is
deliberate: `{ZENODO_DOI}` stands for the data record and is filled in by the
authors before submission.
